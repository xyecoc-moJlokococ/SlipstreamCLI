# Категории внутри подписки

Папка подписки в Smugly может делиться на под-категории: у каждой есть название и (по желанию)
короткое описание — оно и объясняет пользователю, зачем эта группа серверов нужна.

```
Повседневный обход        ← заголовок категории
Обычные VLESS-серверы…    ← описание, необязательно
  🇪🇸 Испания
  🇷🇺 Россия
Обход БС (s3-fuckup)
Туннель через S3-хранилище…
  S3 Мадрид
```

Категории целиком принадлежат панели: клиент их не создаёт, не переименовывает и не сохраняет
между обновлениями. Убрали категорию из выдачи — она исчезнет и в приложении. Пользователь может
только свернуть группу (тап по заголовку), и это состояние живёт до перезапуска — это позиция
чтения, а не настройка.

Ничего не сломается у тех, кто категории не отдаёт: подписка без них выглядит ровно как раньше —
плоский список серверов.

## Как их отдавать

Парсер не привязан к одной схеме: подходит любая из форм ниже, их можно смешивать. Ключи
сопоставляются нестрого — `category`, `Category`, `category_name`, `categoryName` — это один ключ.
Названия и описания принимают `base64:<payload>`, если UTF-8 в выдаче ненадёжен.

### 1. JSON: категория — узел с серверами внутри

```json
{
  "categories": [
    {
      "name": "Повседневный обход",
      "description": "Обычные VLESS-серверы для повседневного интернета.",
      "configs": [ { "remarks": "🇪🇸 Испания", "outbounds": [ … ] } ]
    },
    {
      "name": "Обход БС (s3-fuckup)",
      "description": "Туннель через S3-хранилище из белого списка оператора.",
      "links": ["s3fu://import?name=S3%20Мадрид&config=…"]
    }
  ]
}
```

Именем группы может быть `name` / `title` / `category` / `group` / `label`, описанием —
`description` / `desc` / `subtitle` / `about` / `note`. Ключ, под которым лежат серверы, значения
не имеет: обход рекурсивный, и категорией становится **любой именованный узел, внутри которого
действительно есть серверы**. Корень документа категорией не считается — его `name` описывает всю
подписку.

Сервер — это объект с непустым `outbounds` (конфиг Xray, хранится дословно) **или** строка-ссылка
(`vless://`, `s3fu://`, `slipstream://`, `xray://`, …), в том числе внутри объекта с полем
`link` / `uri` / `url` / `config`. Собственные протоколы приложения существуют только в виде
ссылок, поэтому смешанная группа — норма.

### 2. JSON: категория — поле самого сервера

```json
{
  "categories": [
    { "name": "Повседневный обход", "description": "Обычные VLESS-серверы…" },
    { "name": "Обход БС (s3-fuckup)", "description": "Туннель через S3-хранилище…" }
  ],
  "configs": [
    { "remarks": "🇪🇸 Испания", "category": "Повседневный обход", "outbounds": [ … ] },
    { "name": "S3 Мадрид", "category": "Обход БС (s3-fuckup)", "link": "s3fu://import?…" }
  ]
}
```

Поле категории — `category` / `group` / `folder` / `section`. Блок `categories` (`groups`,
`sections`, `folders`) нужен только ради описаний и **порядка**: категории показываются в том
порядке, в котором их перечислила панель. Описание можно положить и на сам сервер —
`category-description`.

### 3. Список ссылок: маркеры `#category:`

```
#profile-title: Мой VPN
#category: Повседневный обход
#category-description: Обычные VLESS-серверы для повседневного интернета.
vless://…#🇷🇺 Россия
vless://…#🇺🇸 США
#category: Обход БС (Slipstream)
#category-description: DNS-туннель, работает даже при нулевом балансе.
slipstream://import?name=…&config=…
```

Маркер действует до следующего: всё, что идёт ниже, попадает в эту категорию. Пустое значение
(`#category:`) закрывает группу — дальше серверы снова без категории. Тело может быть целиком в
base64, как обычно. Синонимы: `#group:` / `#folder:` / `#section:`, описание —
`#category-description:` / `#group-description:` / `#description:`.

## Мелочи, о которых стоит знать

- Категория без серверов не рисуется. Объявить её можно, но пока в ней пусто — её не видно.
- Серверы, которым панель не назначила категорию, идут первыми, без заголовка. Приложение не
  придумывает им группу «Прочее» — это было бы название, которого панель не давала.
- Категория опознаётся по названию (без учёта регистра и пунктуации), так что
  `Обход БС (s3-fuckup)` из одной формы и `обход бс s3 fuckup` из другой — одна и та же группа.
  Явный `id` на категории тоже поддерживается.
- Перетаскивание профилей в папке с категориями выключено: порядок задаёт панель, а обновление
  всё равно перезапишет группу целиком.
